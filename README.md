# Anthony Combalicer — Developer Portfolio

Personal portfolio and printable résumé built with HTML5, CSS custom properties (Light & Dark themes), and vanilla JavaScript.

- **Live Portfolio:** https://anthonycombalicer66-maker.github.io/
- **Online Résumé:** https://anthonycombalicer66-maker.github.io/resume.html
- **PDF Résumé:** `assets/Anthony_Combalicer_Resume.pdf`

## Featured Projects

1. **[CraftHub](https://anthonycombalicer66-maker.github.io/CraftHub/)** — Searchable Minecraft guide hub with five simultaneous filters and a live match counter.
2. **[Pixel-Descent](https://anthonycombalicer66-maker.github.io/Pixel-Descent/)** — Single-file browser action RPG with dungeon floor progression, live minimap, and a real-time HUD loop.
3. **[BiteRush](https://anthonycombalicer66-maker.github.io/BiteRush/)** — Responsive fast-food ordering storefront with meal-time tabs, live search, wishlists, and real-time cart counters.

## Files

- `index.html` — Blueprint portfolio with bento telemetry bar, `⌘K` command palette, 12-week GitHub activity grid with recent feed, project filters, copyable code snippets, interactive Tekken 7 bracket sandbox, lightbox, and email modal.
- `resume.html` — Printable web résumé with one-tap PDF download.
- `styles.css` & `script.js` — Light/Dark theme tokens, reading progress indicator, responsive layout, scroll-spy, and modal interactions.
- `404.html`, `robots.txt`, `sitemap.xml` — GitHub Pages routing and indexing files.
