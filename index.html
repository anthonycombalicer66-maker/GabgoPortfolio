CraftHub

A searchable Minecraft guide hub where players filter survival tips, creative builds, and tutorials without leaving the page.

  • Instant keyword search combined with five independent filters (category, difficulty, topic, game mode, and version)
  • “Surprise me” discovery action that picks a random matching guide

Under the hood: synchronized multi-filter pipelineJS
filter.js 
function filterGuides(guides, state) {
  const q = state.query.trim().toLowerCase();
  return guides.filter((item) => {
    const matchesText = !q || item.title.toLowerCase().includes(q) || item.tags.some((t) => t.includes(q));
    return matchesText
      && (state.category === "all" || item.category === state.category)
      && (state.difficulty === "all" || item.difficulty === state.difficulty)
      && (state.mode === "all" || item.mode === state.mode);
  });
}

Pixel-Descent

An experimental action RPG engineered to run entirely from a single HTML file—battle through dungeon floors, earn XP, and manage skills and potions.

  • Floor-based dungeon progression (starting at Floor 1 – Lava Cavern) with a live minimap
  • Real-time HUD featuring vitality and mana orbs, XP progress, and a skill/potion hotbar
  • Character progression with gold drops and passive skill points
  • Zero installs or external dependencies—loads straight in the browser

Desktop controls: Best experienced with keyboard and mouse.

Goal
Test how complete a real-time action RPG loop and HUD could be inside a single self-contained HTML file.
Challenge
Keeping player stats, cooldowns, enemies, and minimap rendering synchronized every frame without a game engine.
Outcome & next step
Structured a clean frame loop and modular game state; next step is splitting modules and adding touch controls for mobile play.
Under the hood: delta-timed dungeon frame loopJS
loop.js 
let lastTick = performance.now();
function gameLoop(now) {
  const dt = Math.min((now - lastTick) / 1000, 0.05);
  lastTick = now;
  updatePlayer(dt);
  updateEnemiesAndProjectiles(dt);
  renderDungeonCanvas();
  syncHudOrbsAndMinimap();
  requestAnimationFrame(gameLoop);
}

cart.js 
function updateCartItem(menuId, delta) {
  const nextQty = (cartState.get(menuId) || 0) + delta;
  if (nextQty <= 0) cartState.delete(menuId);
  else cartState.set(menuId, nextQty);
  const totalCount = Array.from(cartState.values()).reduce((sum, n) => sum + n, 0);
  cartBadgeEl.textContent = String(totalCount);
  renderCartSummary();
}
